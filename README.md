# Cube (가제)

2026-2 컴퓨터 그래픽스 최종 프로젝트. 큐브의 27칸이 각각 하나의 방(던전)이고, 큐브 면을 돌리면 그 칸의 방 전체가 같은 각도로 회전하는 로그라이크 액션 어드벤처 FPS.

- 팀원: 강민우, 김헌수
- OpenGL 3.3 Core, 외부 모델·이미지 에셋 없이 코드와 셰이더로 구성

## 현재 상태

GT_Demo 프로토타입에서 시작한 버전입니다. 방 크기는 데모 대비 1.3배(한 변 46 → 약 60)입니다 (`ROOM_SCALE`).

- **허브 (가운데 칸, 13번):** 유리 격자 벽의 기차역. 높이가 다른 8개 선로를 따라 기차가 8방향(가로 4 + 대각선 4)으로 계속 달립니다. 큐브 정중앙이라 어느 면을 돌려도 위치가 변하지 않습니다.
- **웹스윙:** 우클릭을 누르는 순간 보고 있는 곳에 줄을 걸고, 누르고 있는 동안 건 순간의 줄 길이를 유지한 채 진자처럼 흔들립니다(바닥에 긁힐 때만 줄이 짧아짐). 줄이 팽팽하면 중력이 더 세지고 호 아래쪽에서 진행 방향으로 가속해 스윙이 이어지며, 빠를수록 시야각이 넓어지고 화면이 줄 쪽으로 기웁니다. 떼면 관성에 위로 튕기는 힘을 더해 놓고, Space를 누르면 줄을 끊고 바라보는 방향으로 대쉬합니다(높은 포털은 이 대쉬로 닿습니다).
- **기차 이동:** 선로 8개에 기차가 하나씩(객차 4~5량) 달립니다. 달리는 객차에 줄을 걸면 줄에 매달려 흔들리며 끌려가고, 기차가 다가오면 출구 벽에 다음 방 색의 큰 구멍이 열립니다. 객차가 구멍으로 들어가면 매달린 플레이어도 따라 들어가 그 선로가 향하는 칸(가운데 층 8칸 중 하나)으로 넘어가고, 도착한 방의 뒤쪽 벽에서 같은 구멍이 닫히며 튀어나옵니다.
- **방 클리어와 포털:** 방마다 웨이브 3개(적 12, 18, 24마리)를 막으면 클리어. 남은 적이 4마리 이하가 되면 다음 웨이브가 바로 몰려오고, 적이 많아도 동시에 날아오는 적 총알은 6발까지입니다. 적의 절반은 총 대신 빨간 근접형으로, 빠르게 달려와 양팔을 들었다(0.4초) 내려칩니다. 맞은 직후 약 0.3초는 무적이라 여럿에게 한꺼번에 맞아도 한 칸만 깎입니다. 각 면(벽·바닥·천장) 중앙에 그 방향으로 붙은 칸으로 가는 포털이 열립니다 (청록 = 열림, 빨강 = 잠김, 없음 = 큐브 바깥). 벽과 천장 포털은 웹스윙 후 대쉬로 닿습니다.
- **증강:** 방을 깨면 바닥(가운데 포털 자리는 피해서)에 금빛 결정이 도는 증강 물체가 나옵니다. 가까이 가서 F 를 누르면 게임이 멈추고 증강 카드 3장이 뜹니다. 안 받고 방을 나가도 다시 오면 그대로 있습니다. 클릭이나 1/2/3 키로 하나를 고르면 이번 판 동안 플레이어가 영구 강화됩니다(R 로 처음부터 하면 초기화). 지금은 스탯 강화 17계열 58개(연사, 탄속, 관통, 다중 사격, 최대 체력, 이동·달리기 속도, 점프, 불릿타임 지속·회복, 웹 사거리, 스윙 대쉬, 스윙 가속, 공중 조종, 놓기 반동, 클리어 회복, 킬 회복)이고, 같은 계열은 I → II → III 순서로만 나옵니다. 후보는 아직 안 나온 것부터 뽑습니다. 스킬 강화 자리는 비워 두었습니다(`augments.cpp` 의 표에 `skill = true` 계열을 추가하면 같이 섞임). Tab 큐브 화면 왼쪽 위에서 지금까지 얻은 증강과 단계를 볼 수 있습니다.
- **방마다 다른 그래픽:** 방(칸)마다 렌더 스타일이 다릅니다. 허브는 실사풍(프레넬·정규화 반사광, 필름 톤, 외곽선 없음), 26번 경기장은 데모 원래 화면, 나머지 방은 칸 번호에 따라 툰(빛 3단계 + 굵은 외곽선), 픽셀(큰 픽셀 + 색 단계 + 베이어 디더링), 누아르(흑백 + 붉은색만 남김 + 필름 입자), 네온(어두운 표면 + 물체 격자선 + 빛나는 외곽선), 청사진(파란 종이 + 흰 선)입니다. 같은 장면 셰이더와 합성 셰이더가 `style` 값에 따라 조명 모델과 후처리를 바꿉니다.
- **그래픽:** 코드로 그린 512×512 텍스처 6장(콘크리트, 바닥 타일, 유리, 열차 금속판, 벽 패널, 상자)을 텍스처 배열 하나에 올리고 밉맵·비등방 필터를 씁니다. 텍스처 좌표는 물체 공간 좌표를 면 방향 평면에 투영해 만듭니다. 점광원은 방마다 수십 개를 두고 카메라에서 가까운 24개만 셰이더로 보냅니다(Phong + 거리 감쇠). 허브 유리 난간은 뒤에서부터 정렬해 알파 블렌딩합니다.
- **회전:** 큐브 회전은 제한 없음. 포털 너머의 방은 이동하는 순간의 큐브 배치로 정해지므로, 돌리면 같은 포털이 다른 방으로 이어집니다. 클리어 기록은 방(칸 번호)을 따라 움직입니다.

## 조작

| 화면 | 입력 |
|---|---|
| FPS | WASD 이동, Ctrl 달리기, Space 점프, 마우스 시점, 우클릭 누르고 있기 = 줄 걸기(웹스윙), 웹스윙 중 Space = 줄 끊고 바라보는 방향으로 대쉬, 좌클릭 발사, Shift 누르고 있기 = 불릿타임(시간 감속), Tab 큐브 화면, R 처음부터, ESC/Q 종료 |
| 증강 고르기 | 증강 물체 가까이에서 F, 카드 클릭 또는 1/2/3 |
| 큐브 화면 | 바깥 드래그: 큐브 전체 회전 / 칸 위 드래그: 한 면 회전 / 더블클릭·Enter: 그 칸으로 바로 이동(개발용) / R: 큐브 초기화 / Tab: 돌아가며 회전 적용 |

## 소스 구성 (`Cube/Cube`)

| 파일 | 내용 |
|---|---|
| `cube.h` | 모든 파일이 공유하는 타입, 상수, 전역 변수(extern), 함수 원형 |
| `main.cpp` | 입력 콜백, 초기화, 메인 루프 |
| `util.cpp` | 셰이더 로드, 메쉬(상자, 사면체, 원판) |
| `textures.cpp` | 코드로 그리는 텍스처 배열 |
| `world.cpp` | 재질, 큐브 27칸 상태와 면 회전, 방 생성, 충돌 |
| `hub.cpp` | 허브 기차역, 선로와 기차 위치, 벽 구멍 계산 |
| `augments.cpp` | 증강 목록(계열·단계·효과), 후보 뽑기, 고르기, 카드 위치 |
| `game.cpp` | 플레이어, 적, 총알, 웹스윙, 기차 매달리기, 포털, 방 이동, 매 프레임 갱신 |
| `cubeview.cpp` | 큐브 화면(Tab) 조작과 그리기, 월드 회전 적용 |
| `render.cpp` | 렌더 파이프라인(그림자, HDR, 인스턴싱, 반투명, 블룸, 합성), 방별 스타일, 구멍 그리기 |
| `hud.cpp` | HUD (2D 동차좌표 변환, 비트맵 글꼴) |
| `tests.cpp` | `--shot` 스크립트 테스트, `--bench` 성능 측정 |

## 빌드

- 최신 코드 받기: 저장소 맨 위의 `pull.bat` 더블클릭 (`git pull --ff-only`, 내 변경과 겹치면 멈추고 알려줌)

- Visual Studio (v145 툴셋, C++20), `Cube/Cube.slnx`, x64
- GLEW, GLFW, GLM 헤더와 라이브러리는 Windows SDK 폴더에 넣어 둔 설정을 씁니다
  - include: `<GL/glew.h>`, `<GL/glfw3.h>`, `<gl/glm/glm.hpp>`
  - link: `opengl32.lib glew32.lib glfw3.lib`
- 셰이더(`*.glsl`)는 실행 위치 기준 상대 경로로 읽으므로 실행 파일과 같은 폴더나 프로젝트 폴더에서 실행해야 합니다
- `Cube.exe --bench [가로 세로]`: 수직동기를 끄고 장면마다 카메라를 한 바퀴 돌리며 평균·1% 최저 프레임 시간, 드로우 콜, 삼각형 수를 재서 `bench_result.txt` 로 저장 (Release 로 실행)
- `Cube.exe --shot`: 허브 → 기차 → 방 → 클리어 → 포털 → 큐브 회전 → 재시작을 스크립트로 실행하고 결과를 콘솔에 출력하는 확인용 모드

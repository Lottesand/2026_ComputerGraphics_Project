# Cube (가제)

2026-2 컴퓨터 그래픽스 최종 프로젝트. 큐브의 27칸이 각각 하나의 방(던전)이고, 큐브 면을 돌리면 그 칸의 방 전체가 같은 각도로 회전하는 로그라이크 액션 어드벤처 FPS.

- 팀원: 강민우, 김헌수
- OpenGL 3.3 Core, 외부 모델·이미지 에셋 없이 코드와 셰이더로 구성

## 현재 상태

GT_Demo 프로토타입에서 시작한 버전입니다. 방 크기는 데모 대비 1.3배(한 변 46 → 약 60)입니다 (`ROOM_SCALE`).

- **허브 (가운데 칸, 13번):** 유리 격자 벽의 기차역. 높이가 다른 8개 선로를 따라 기차가 8방향(가로 4 + 대각선 4)으로 계속 달립니다. 큐브 정중앙이라 어느 면을 돌려도 위치가 변하지 않습니다.
- **웹스윙:** Shift 를 누르는 순간 보고 있는 곳에 줄을 걸고, 누르고 있는 동안 줄을 감으며 진자처럼 흔들립니다. 떼면 관성을 유지한 채 놓습니다.
- **기차 이동:** 달리는 객차에 줄을 걸면 객차 옆에 매달리고, 객차가 벽으로 들어가면 그 선로가 향하는 칸(가운데 층 8칸 중 하나)으로 넘어갑니다.
- **방 클리어와 포털:** 방마다 웨이브 2개를 막으면 클리어. 각 면(벽·바닥·천장) 중앙에 그 방향으로 붙은 칸으로 가는 포털이 열립니다 (청록 = 열림, 빨강 = 잠김, 없음 = 큐브 바깥). 벽과 천장 포털은 웹스윙으로 닿습니다.
- **회전:** 큐브 회전은 제한 없음. 포털 너머의 방은 이동하는 순간의 큐브 배치로 정해지므로, 돌리면 같은 포털이 다른 방으로 이어집니다. 클리어 기록은 방(칸 번호)을 따라 움직입니다.

## 조작

| 화면 | 입력 |
|---|---|
| FPS | WASD 이동, Ctrl 달리기, Space 점프, 마우스 시점, Shift 누르고 있기 = 줄 걸기(웹스윙), 좌클릭 발사, 우클릭 유지 집중(시간 감속), Tab 큐브 화면, R 처음부터, ESC/Q 종료 |
| 큐브 화면 | 바깥 드래그: 큐브 전체 회전 / 칸 위 드래그: 한 면 회전 / 더블클릭·Enter: 그 칸으로 바로 이동(개발용) / R: 큐브 초기화 / Tab: 돌아가며 회전 적용 |

## 빌드

- Visual Studio (v145 툴셋, C++20), `Cube/Cube.slnx`, x64
- GLEW, GLFW, GLM 헤더와 라이브러리는 Windows SDK 폴더에 넣어 둔 설정을 씁니다
  - include: `<GL/glew.h>`, `<GL/glfw3.h>`, `<gl/glm/glm.hpp>`
  - link: `opengl32.lib glew32.lib glfw3.lib`
- 셰이더(`*.glsl`)는 실행 위치 기준 상대 경로로 읽으므로 실행 파일과 같은 폴더나 프로젝트 폴더에서 실행해야 합니다
- `Cube.exe --shot`: 허브 → 기차 → 방 → 클리어 → 포털 → 큐브 회전 → 재시작을 스크립트로 실행하고 결과를 콘솔에 출력하는 확인용 모드
